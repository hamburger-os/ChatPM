# 项目上下文（供 AI）

## 目标
以群聊为入口，让 AI 像项目经理一样提取**有证据的**任务和风险、追问细节、主动跟进、生成周报月报，降低人工维护负担。

## 当前状态
 当前实现项目群聊、候选确认、单消息 AI 分析、提醒与当前状态报告草稿；尚未完成生产验收。不得声称已实现 WebSocket、文件知识库、SSO、跨消息智能规划。

## 核心闭环
项目创建与成员加入 → 群聊对话 → 结构化候选任务/风险 → 授权确认 → 正式任务 → 后台跟进 → 更新状态 → 生成当前项目状态的待审核周/月报告草稿（尚无完整证据链接和历史周期差异）。

## 当前非目标
第一版不做多 Agent 自治、自建通用工作流引擎、全量微服务拆分、任意外部工具执行、高级甘特排程或复杂多渠道双向同步。

## 决策依据
中文 `docs/design/` 为产品负责人的审查入口。实现前应检查审批状态与 ADR，不得把模型猜测的负责人、期限当作事实。
