# ChatPM v0.1 实施状态与剩余风险

**状态：实验性 MVP；未完成生产验收。**

| 模块 | 当前代码覆盖 | 尚未覆盖 |
|---|---|---|
| 身份与项目 | 邮箱账号、项目权限、成员加入 | 企业 SSO、邀请邮件、细粒度角色 |

| AI | 默认关闭、显式启用、单消息候选抽取、显式引用候选的多轮澄清、人工确认、项目日调用预算 | 自动语义关联、长时知识上下文、模型评估、多供应商、Token 费用分析 |

## 运行条件
本地 Node.js 22+、PostgreSQL 17、环境变量、三个进程 API/Worker/Web。模型未配置时自动提取不会工作，但人工任务及报告仍可使用。

## 生产门槛
需要补齐租户/项目越权集成测试、Outbox 重放及失败告警、数据删除/隐私治理、模型费用预算、实时连接、文件安全处理和真实场景回归。CI 构建/单元测试通过**不等于**上述生产验收。

## 本轮审查与修复（2026-10-12）
修复：消息游标并发漏读、任务重新排期突破冷却、周/月报统计截断与草稿不刷新；补充 PostgreSQL HTTP 冒烟回归。尚未完成：Outbox 失败隔离/人工重放、消费者与模型真实集成、安全/隐私/成本预算、跨消息 AI 对话闭环。上述未完事项不得被本轮可靠性修复视为已通过生产验收。
