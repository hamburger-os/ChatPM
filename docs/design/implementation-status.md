# ChatPM v0.2 实施状态与剩余风险

**状态：实验性 MVP；未完成生产验收。**

| 模块 | 当前代码覆盖 | 尚未覆盖 |
|---|---|---|
| 身份与项目 | 邮箱账号、项目权限、成员加入 | 企业 SSO、邀请邮件、细粒度角色 |
| 聊天 | 消息入库、幂等、事务级消息顺序、Web 页面轮询 | WebSocket、文件、编辑撤回 |
| AI | 默认关闭、显式启用、单消息候选抽取、显式引用候选的多轮澄清、人工确认、项目日调用预算 | 自动语义关联、长时知识上下文、模型评估、多供应商、Token 费用分析 |
| 任务与风险 | 正式任务、状态乐观锁、风险候选 | 依赖编排、风险升级与关闭 UI |
| 自动跟进 | 持久化计划、工作时间、提醒冷却、站内提醒、Outbox 指数退避/隔离/授权重放 | 节假日、私信、复杂升级、运维告警与灾备演练 |
| 汇报 | 单次数据库快照全量统计、可重新生成草稿、发布后不可变 | 历史完成率还原、附件证据、图表 |
| 安全与运维 | 项目权限、会话、Origin、限速、Outbox 可恢复失败、AI 每日调用限额 | 生产攻防测试、完整领域审计、数据删除、逐 token 成本治理 |

## 运行条件
本地 Node.js 22+、PostgreSQL 17、环境变量、三个进程 API/Worker/Web。模型未配置时自动提取不会工作，但人工任务及报告仍可使用。

## 生产门槛
需要补齐更广范围的权限/失败告警、数据删除和隐私治理、真实模型成本评测、实时连接、文件安全与恢复演练。CI 构建/单元测试通过**不等于**上述生产验收。
