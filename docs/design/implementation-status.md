# ChatPM v0.1 实施状态与剩余风险

**状态：实验性 MVP；未完成生产验收。**

| 模块 | 当前代码覆盖 | 尚未覆盖 |
|---|---|---|
| 身份与项目 | 邮箱账号、项目权限、成员加入 | 企业 SSO、邀请邮件、细粒度角色 |
| 聊天 | 消息入库、幂等、Web 页面轮询 | WebSocket、文件、编辑撤回 |
| AI | 默认关闭、显式启用、单消息候选抽取、人工确认 | 跨消息知识分析、完整模型评估、多模型 |
| 任务与风险 | 正式任务、状态乐观锁、风险候选 | 依赖编排、风险升级与关闭 UI |
| 自动跟进 | 持久化计划、工作时间、站内提醒 | 节假日、私信、复杂升级与死信管理 |
| 汇报 | 当前状态快照周/月报草稿、人工发布 | 历史完成率还原、附件证据、图表 |
| 安全与运维 | 项目权限、会话、Origin、限速、Outbox | 生产攻防测试、完整审计、删除、费用控制 |

## 运行条件
本地 Node.js 22+、PostgreSQL 17、环境变量、三个进程 API/Worker/Web。模型未配置时自动提取不会工作，但人工任务及报告仍可使用。

## 生产门槛
需要补齐租户/项目越权集成测试、Outbox 重放及失败告警、数据删除/隐私治理、模型费用预算、实时连接、文件安全处理和真实场景回归。CI 构建/单元测试通过**不等于**上述生产验收。
