# ChatPM 第二轮架构与实现审查（2026-10-12）

**审查对象**：`main` 的 v0.1 MVP（API、Worker、核心 SQL、Next.js 前端、集成冒烟测试、CI、中文设计及 AI 契约）。本轮修复以独立 PR 交付，**不等于生产验收或全部设计获批**。

## 总体判断
继续采用 TypeScript 模块化单体、Fastify API + 独立 Worker、PostgreSQL 事实源、候选与正式项目状态隔离、人工确认和事务 Outbox。MVP 体量不值得引入微服务、通用 Agent 框架或 Kafka。单 API 文件与单 Worker 文件属于现阶段实现简化，不应成为长期模块边界。

## 缺陷分级与处理

| 优先级 | 问题与证据 | 本轮结果 |
|---|---|---|
| P0 | `messages.seq` 由 Identity 在事务提交前分配；并发提交逆序时 `after=seq` 永久漏消息 | 统一 `insertMessage`，按项目持事务 advisory lock；新增并发回归 |
| P0 | Outbox 最多 8 次尝试后事件仍未完成，无持久失败归因、重放管理、告警 | **未完成，下一里程碑第一项** |
| P1 | 报告聚合只读取最近 200 条任务且显示为全量 | 单 SQL MVCC 快照完整聚合、限制明细 |
| P1 | 草稿已有相同周期键时永不刷新，导致过时周报/月报 | 草稿 UPSERT 重算，发布后不可修改 |
| P1 | 任务重排重新设置短期提醒，可能绕过最近一次发送冷却 | 保留 `last_sent_at` 冷却下限 |
| P1 | `apps/api/src/server.ts` 和 `apps/worker/src/worker.ts` 业务逻辑密集，模型调用耦合 Worker | 未完成，按领域模块渐进拆分 |
| P1 | AI 只处理单条消息；澄清问题缺少明确关联、回答追踪，无法持续闭环 | 未完成，需产品审批后实施 |
| P1 | `proposed_changes` 尚无完整证据片段、Prompt/模型版本、审查前后版本等治理字段 | 未完成 |
| P1 | 缺少锁文件、版本化迁移治理、权限/安全恢复/费用测试 | 未完成，不应生产部署 |
| P2 | 站内 5 秒轮询、无附件与独立知识库 | 已知 MVP 限制，非首要一致性风险 |

## 推荐的下一个可验收里程碑：可靠任务事件与 AI 追问闭环
1. **可靠事件管理**：Outbox 持久错误码、指数退避、最大重试隔离、负责人可见的失败状态/授权重放；工作指标（最老待处理事件、超限数、模型错误率）。支持重复重放且不产生额外候选或聊天。
2. **精简领域模块**：在 `packages/core/src` 先分 Conversation、Work、Automation、Reporting 的命令和查询，路由与 Worker 仅调用公开接口；禁止跨模块直接改写聚合表。不引入无用接口层或多套 DTO。
3. **对话中待澄清事项**：增加 `ClarificationThread` 或等价单一聚合，引用项目、来源消息、候选和待补字段；将后续回答绑定同一线程，附证据和版本、申请负责人确认；超时/取消可恢复；不凭模糊答复直接改正式任务。
4. **AI 治理与适配**：抽象单模型 Provider 接口，限制上下文、脱敏与传输同意范围，记录模型与 Prompt 版本、token 及费用；先构造评测集（误提取、漏提取、提示注入、误追问），再上线连续对话。
5. **可复现工程**：提交依赖锁文件、版本化可重放数据库迁移，CI 增加并发数据库、失败重试、越权、真实时区边界及低成本模拟模型测试。

## 不应现在做的事
- 仅因“AI 项目经理”名称而使用多个互相自治的 Agent。
- 以向量相似度替代任务状态/审批/风险事实。
- 未测吞吐时使用 Redis/Kafka 作为新的权威消息序号或事实来源。
- 没有用户授权时把全部聊天和附件批量发送第三方模型。
- 无生产测试就把 MVP 标为企业生产就绪。

## 验收标准
- 同项目并发两笔消息事务逆序完成时，增量消息游标不会漏读；不同项目并发不互相阻塞。
- 同一任务重新排期后，距上次实际提醒不足配置冷却时间的消息不得发送。
- 超过 200 个任务的项目报告显示正确全量任务数；草稿可更新，发布后不可覆盖。
- 下一里程碑：8 次失败事件必须可观测、可安全重放；澄清答复能追踪到唯一候选且未经批准不能修改正式任务。
- 上述测试必须有真实 CI 结果；文档检查和类型检查不能代替生产级安全与恢复验证。

**本轮边界**：修复前三类一致性问题及相关文档，剩余 P0/P1 明确列为后续交付，不声称已完成。
