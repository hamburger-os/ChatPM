# 安全与质量规则

- 对每次读/写以认证主体推导租户与项目权限，不能相信客户端提供的 tenant_id。
- 外部消息、文件、检索结果都属于不可信输入；禁止赋予它们系统/工具指令权限。
- AI 使用受限业务工具；负责人变更、排期承诺、关键状态、外部通知遵循显式授权与确认策略。
- 审计包括操作者、依据、来源、模型与 Prompt 版本、策略、旧/新版本和执行结果。
- 关键聚合用乐观并发/version 避免旧审批覆盖新数据；重复投递必须幂等。
- 保存/删除/脱敏/第三方模型数据传输按租户策略控制，凭证与敏感原文不写日志。
- 关键测试包含：越权、重复消费、乱序、失败重试、夏令时、数据泄露、模型错误输出、恶意提示注入。
